# Prism · 典藏卡编辑器

在本机服务运行时，打开 [Prism 工作台](http://127.0.0.1:4174/)。访客可浏览工作台和公开社区。新建、导入、打开私有项目或使用资产时会要求登录。

「成品预览」沿用「藏光 · 硬质收藏册」的放大查看器。卡片从画布上正在编辑的卡面位置展开，首次打开会翻转一圈。关闭时，卡片回到画布上的位置。移动指针或拖动可改变光照角度，左右箭头切换正反面，点击卡片或按 Esc 收回。在工作台的「效果库」选择星空闪、几何镭射、细闪或工艺本色。成品预览读取项目保存的样式，并按当前工艺区域渲染反光。数字图使用该样式的平面材质示意。

## 开发与评审

| 用户任务 | 工作台功能 |
| --- | --- |
| 管理卡牌 | 项目库支持新建、搜索、打开、复制、归档及恢复。可从模板或空白开始，也可导入 `.cardproj` 项目包。 |
| 排版与工艺 | 编辑器默认进入「设计」，左侧可换主图、改卡名，底部切换正反面。「效果」先显示当前面的已应用工艺，可打开预设库添加。选定区域时，画布用绿色高亮，区域绘制确认后写入项目。 |
| 检查和交付 | 导出抽屉提供数字图、印刷文件和项目备份。阻塞问题可定位至对应卡面、图层、效果或底材。导出任务锁定项目快照，关闭抽屉后仍可返回查看进度和重试。 |
| 保存恢复 | 项目写入本机 SQLite。顶栏显示已保存、保存中或失败，返回项目库前会提交待保存修改。保存失败时可重试或下载项目包。两个窗口修改同一版本时可另存副本。 |

编辑工作台覆盖项目管理、图层编辑、作用区域、工艺设置、预览和导出。首个生产版本仍需拿到实际印厂的交稿规范与色彩配置，完成 PDF/X 预检、设备读版和实体打样。当前两套技术配置用于验证文件包和交稿流程。

## 本机运行

从仓库根目录按 [本机运行说明](../README.md#本机运行) 安装依赖、构建并启动服务。修改前端后再次执行 `pnpm build`，再刷新浏览器。开发模式可在服务运行时执行 `pnpm dev`。

## 项目数据

### 在同一网络接力编辑

1. 在本机版打开要共享的项目，从「项目中的卡牌 → 局域网接力」开启共享。
2. 从本机传送面板中的证书到第二台电脑。macOS 上打开「钥匙串访问」，导入证书并在其信任设置中允许 SSL。Windows 上将证书导入当前用户的「受信任的根证书颁发机构」。
3. 在第二台电脑的浏览器打开面板给出的完整 HTTPS 地址，输入本次共享密码。两个设备通过同一项目库接力编辑。发生保存冲突时可以下载自己的草稿，再打开最新版本。
4. 主机可在同一面板更换密码或停止共享。服务重启后需要重新开启共享。

### 本机存储

- 项目、交付记录和个人资产写入当前账号的数据库。默认存储目录为 `~/Library/Application Support/Prism`，可通过 `--data-dir` 指定。退出后工作台隐藏私有数据，登录原账号后恢复显示。
- 旧版服务的共享项目库由主机迁入指定账号。运行 `python scripts/migrate-account-library.py --data-dir "本机 Prism 数据目录" --account "已注册的账号 ID 或旧版账号名"`。迁移保留原库，备份后检查记录并拒绝覆盖已有的不同内容。
- 浏览器独有的旧项目可从原环境导出 `.cardproj`，登录后导入。备份整个账号及项目库时，先停止服务再复制数据目录。

### 个人资产和社区

登录后，在编辑器的「项目中的卡牌」选择「设为资产」。工作台「资产」可查看原创和已领取的卡，下载 `.prismasset`，或使用所选版本创建新项目、加入已有项目。从原创资产选择「发布到社区」可核对共享内容并发布固定版本。同一账号可在另一设备导入下载过的资产包。已有 `.cardproj` 工程继续从工作台导入。

需要跨网络运行社区时，构建服务版前端，在有持久磁盘的主机启动 `python server.py --public-origin https://你的域名 --data-dir /持久数据目录`。将同一域名的 HTTPS 反向代理转发至 `127.0.0.1:4174`，保留外部 Host 头。该模式允许访客浏览公开作品，项目、个人资产、领取和交付操作要求登录。操作员可用 `python community_store.py --data-dir /持久数据目录 reports` 查看举报，用 `block 作品ID` 下架作品。

邮箱验证码、绑定邮箱和找回密码使用 SMTP。部署环境需设置 `PRISM_SMTP_HOST`、`PRISM_SMTP_FROM` 和邮件服务要求的 `PRISM_SMTP_USERNAME`、`PRISM_SMTP_PASSWORD`。`PRISM_SMTP_TLS` 选 `starttls` 或 `ssl`，默认端口分别为 587 或 465，也可设置 `PRISM_SMTP_PORT`。发件及上线域名确定后，用测试账号核对验证码、找回和 Secure 会话。隔离的本机测试可用 `PRISM_AUTH_TEST_OUTBOX` 指向私有临时文件来收验证码或验证链接，公网模式只接收 SMTP 配置。

账号、发布版本、领取记录、资产包签发密钥及操作记录位于 `community.sqlite3`。账号项目和个人资产位于 `accounts/`。恢复演练使用独立数据目录核对账号、原始版本、素材和已签发资产包。

`asset_events` 记录发布通过、领取入库、资产包生成和复用入项目。生成资产包的记录表示服务器已返回文件，用户保存到磁盘由浏览器处理。

处理图片权利投诉时，可用 `resources 作品ID --edition 版本号` 核对素材标识，再用 `restrict 作品ID --edition 版本号 --resource 素材标识 --reason "替换原因"` 限制该图片在同一作品各版本中的分发。领取者会在账号资产中看到受影响图层和替换入口。已加入项目的稿件由编辑者自行处理。

## Vercel 网页版

纯静态构建使用 `pnpm build:browser` 生成 `dist/`，展示游客工作台。账号项目、资产和社区需要同站点的 Prism 服务与持久存储。旧版静态站点的浏览器数据由原地址保留，可从原版本导出项目包。

## 本轮验证

- v0.7 使用隔离的 HTTPS 服务、测试邮箱和两个 Chrome 会话验证注册、发布双面卡、领取、下载、同账号导回资产、复用、编辑及保存重开。验证了跨标签退出、跨账号隔离、资产包篡改拒绝和测试数据恢复。公网邮件送达及两台实体设备验收待完成。
- Chrome 实测画布拖动、图层排序与分组、中英文混排、正反面、画笔与擦除、多边形和组合区域。成品预览验证了取卡、随指针反光、翻面、样式切换、自动赏光和回位。
- 本机项目库实测新建、退出前自动提交、换浏览器会话、重启服务恢复、归档与恢复、旧版 IndexedDB 迁移、并发修改另存、保存响应中断后重试和项目包往返。
- 浏览器下载正反面 PNG、背面 JPEG 与两套技术印刷包。使用独立 Poppler 读版，核对 CMYK 保留、两面专色与纯 K 独立版逐像素一致、TrimBox 和 1 位 TIFF。公开界面截图见 [项目首页](../README.md#界面预览)。
- 印刷包用于技术打样参考。两套配置为技术验证配置，彩稿为栅格 CMYK。正式 PDF/X、工厂 ICC、实际 RIP 验收和实体打样待完成。正式中文字体分发、完整色彩及矢量交稿约束、压力场景性能仍需专项验收。
