# Prism · 典藏卡工作室

在本机服务运行时，打开 [我的卡牌](http://127.0.0.1:4174/)。从项目库新建、导入或打开卡牌后进入编辑器。编辑地址可刷新并重新打开同一项目。

「成品预览」沿用「藏光 · 硬质收藏册」的放大查看器。卡片从画布上正在编辑的卡面位置展开，首次打开会翻转一圈。关闭时，卡片回到画布上的位置。移动指针或拖动可改变光照角度，左右箭头切换正反面，点击卡片或按 Esc 收回。在工作台的「效果库」选择星空闪、几何镭射、细闪或工艺本色。成品预览读取项目保存的样式，并按当前工艺区域渲染反光。数字图使用该样式的平面材质示意。

## 开发与评审

| 用户任务 | Demo 交互与验收 |
| --- | --- |
| 管理卡牌 | 项目库支持新建、搜索、打开、复制、归档及恢复。可从模板或空白开始，也可导入 `.cardproj` 项目包。 |
| 排版与工艺 | 编辑器默认进入「设计」，左侧可换主图、改卡名，底部切换正反面。「效果」先显示当前面的已应用工艺，可打开预设库添加。选定区域时，画布用绿色高亮，区域绘制确认后写入项目。 |
| 检查和交付 | 导出抽屉提供数字图、印刷文件和项目备份。阻塞问题可定位至对应卡面、图层、效果或底材。导出任务锁定项目快照，关闭抽屉后仍可返回查看进度和重试。 |
| 保存恢复 | 项目写入本机 SQLite。顶栏显示已保存、保存中或失败，返回项目库前会提交待保存修改。保存失败时可重试或下载项目包。两个窗口修改同一版本时可另存副本。 |

编辑工作台覆盖项目管理、图层编辑、作用区域、工艺设置、预览和导出。首个生产版本仍需拿到实际印厂的交稿规范与色彩配置，完成 PDF/X 预检、设备读版和实体打样。当前两套技术配置用于验证文件包和交稿流程。

## 本机运行

从仓库根目录按 [本机运行说明](../README.md#本机运行) 安装依赖、构建并启动服务。修改前端后再次执行 `pnpm build`，再刷新浏览器。开发模式可在服务运行时执行 `pnpm dev`。

## 项目数据

- 默认数据库为 `~/Library/Application Support/Prism/projects.sqlite3`。启动时可用 `--data-dir` 指定其他目录。
- 项目包含正反面、导入的图片、图层、蒙版和工艺配置。关闭浏览器或重启服务后可重新打开，换同一台电脑上的浏览器也能访问同一项目库。
- 从原来使用 Prism 的浏览器打开同一地址时，会尝试把旧版 IndexedDB 项目迁入本机库。旧记录会保留，重复打开时按项目标识去重。如果访问地址或浏览器不同，可从旧环境导出项目包再导入。
- 单张卡可以在编辑器里导出 `.cardproj`。如需复制整个库，先停止 Prism 服务再复制数据库目录。

## 本轮验证

- Chrome 实测画布拖动、图层排序与分组、中英文混排、正反面、画笔与擦除、多边形和组合区域。成品预览验证了取卡、随指针反光、翻面、样式切换、自动赏光和回位。
- 本机项目库实测新建、退出前自动提交、换浏览器会话、重启服务恢复、归档与恢复、旧版 IndexedDB 迁移、并发修改另存、保存响应中断后重试和项目包往返。
- 浏览器下载正反面 PNG、背面 JPEG 与两套技术印刷包。使用独立 Poppler 读版，核对 CMYK 保留、两面专色与纯 K 独立版逐像素一致、TrimBox 和 1 位 TIFF。公开界面截图见 [项目首页](../README.md#界面预览)。
- 印刷包用于技术打样参考。两套配置为技术验证配置，彩稿为栅格 CMYK。正式 PDF/X、工厂 ICC、实际 RIP 验收和实体打样待完成。正式中文字体分发、完整色彩及矢量交稿约束、压力场景性能仍需专项验收。

卡册动效、材质样式和纹理的来源及许可见 `public/assets/album/来源.txt`。
